# 移民官升級計畫 — 國考題庫像素 RPG（初版）

2027 移民行政三等一般組讀書工具。純靜態網站，可放在 GitHub Pages。

## 使用方式
1. 直接開啟 index.html，或將 index.html、style.css、app.js 上傳至 GitHub 儲存庫根目錄，在 Settings → Pages 啟用部署。
2. 打開「開始練題」做示範題，確認記錄與等級正常。
3. 在「題庫／備份」下載 JSON 範例，按該格式建立自己的題庫並匯入。
4. 每週「匯出完整備份」，保存答案歷史。

## 題庫資料格式
JSON 陣列，每道題須有：
- `id`: 唯一且穩定的題目 ID，例如 `115-immigration-3-admin-001`。
- `subject`: 六科之一，名稱需完全一致：`行政法`、`入出國及移民法規`、`移民執法與刑事法`、`外國文（英文）`、`國文`、`法學知識與英文`。
- `year`: 年度，西元數字。
- `source`: 官方考古題來源文字；須如實標示。
- `topic`: 章節標籤。
- `question`: 題幹。
- `choices`: 四項選項文字陣列。
- `answer`: 正確選項的索引 0、1、2 或 3（分別是 A、B、C、D）。
- `explanation`: 解說（可留空）。

**目前內建 10 題為原創示範，非官方歷屆考題。** 官方題庫尚需取得原卷、解析/擷取、核對題號和答案及法規適用日期。申論題未實作。請勿把範例資料當成已完成的官方全題庫。

## 成績指標注意
主頁的「練習正確率指標」會統計每科至少做過 20 題不同題目的科目，取每題最近一次作答的平均表現。這**不是**三等考試成績或錄取機率；目前示範題數不足，不會顯示虛假的預估分數。等匯入正式題庫後，可加入最近 N 份整卷的計時模考、權重與可信區間。

## 儲存與下一階段
目前使用 localStorage 儲存在當前瀏覽器，未串接雲端。因此**不能跨裝置自動同步**、清除瀏覽器資料可能遺失紀錄。先靠 JSON 備份/還原。後續 B 版升級可以接 Supabase（帳號登入、Row Level Security、跨裝置同步）。部署前不要把任何 service role key、密碼寫入網頁程式碼。

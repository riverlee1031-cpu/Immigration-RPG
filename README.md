# 移民官升級計畫 — 正式歷屆題庫

移民行政三等備考工具，納入三等與四等官方歷屆測驗題。四等題保留原始等別，作為三等基礎練習。

備考類別固定為「三等移民行政（一般組）」，不提供四等備考類別或等別篩選。練習依科目與年度選題，合併使用三等及四等歷屆原題；題目後的三等／四等只代表原始試題出處。

115 年起新制固定六科：共同科目為國文、法學知識與英文；專業科目為外國文（英文）、行政法、入出國及移民法規、移民執法與刑事法。舊制國境執法與刑事法維持原題出處並按新科目名稱分類；200 道國土安全與移民政策題保留為舊制補充，尚未逐題核對新制大綱，不納入預設練習或六科熟練度。既有紀錄、收藏與筆記保留，可從原卷明細與錯題／收藏複習。預設練習題共 1,575 道。

## 收錄範圍

- 民國 111–115 年（2022–2026），共五年、63 份原卷、1,775 道測驗題。
- 三等移民行政選試英文；115 年為一般組選試英文。
- 四等移民行政。依考選部實際開列科目收錄，不自行補造科目。
- 測驗題可作答、自動判分、錯題重練；每題標示年度、等別、原始科目與題號。
- 申論、作文、翻譯保留於原卷，可閱讀，尚未提供線上作答或評分。

所有原始試卷、標準答案與更正答案來自考選部考畢試題查詢平臺。各卷網址、原卷 SHA-256、頁數、測驗題數列於 `data/bank.json`。練題介面以文字顯示單題題幹與四個選項，閱讀題附共用文章，英文留白位置轉為底線。PDF 特殊字形轉為一般文字；無法擷取的四份試卷選項已依原卷人工轉寫。原卷僅作為題庫來源備查。

更正答案優先於初版標準答案。可接受多個單一選項的題目依公告判分；一律給分題亦依公告處理。判分依官方公告，法規答案代表考試當年版本；本站逐項解析為依原題、法規及官方資料整理的學習說明，並非考選部官方解析。

## 使用及備份

透過 GitHub Pages 或本機 HTTP 伺服器開啟，因題庫以 fetch 載入，請勿以 file:// 直接開啟。

紀錄儲存在當前瀏覽器 localStorage，未提供雲端同步。定期在「題庫／備份」匯出完整備份。舊版 `immigration-quest-v1` 資料原樣保留，可單獨匯出；新版正式題紀錄使用 `immigration-quest-official-v2`，不混入示範題成績。

每科每輪抽 10 題，不重複且優先未做題；篩選不足 10 題時使用該範圍全部題目。作答即儲存，可續答；每輪記錄正確、錯誤及未答數。常錯題定義為歷史答錯至少兩次，即使之後答對仍保留；收藏及筆記由使用者自行保存。備份包含完整作答、收藏、筆記、輪次、進行中的練習及模考設定。

全部 1,775 道測驗題（含 200 道舊制政策補充題）均附答題理由、A–D 四項解析與整理依據，於送出答案後顯示。原題語意、法規版本或官方答案有疑義時另加提示，仍保留官方給分方式。解析依科目與年度儲存在 `data/explanations-*.json`，下載失敗會明確提示重新整理。一律給分題不計入首次作答熟練度。筆試目標差距使用使用者輸入的六科完整模考成績，普通科目每科 10%、四科專業科目每科 20%，依現行考試規則第 6 條計算。預設 70 分僅為可調整的讀書目標，不是官方錄取線；未填完整成績時不產生上榜差距或錄取機率。

## 部署與驗證

推送 `main` 後，由 `.github/workflows/pages.yml` 驗證並部署。執行 `node tools/verify-bank.cjs` 核對每卷題數、題號連續性、等別、年度、答案範圍及原卷資產完整性。

執行 `node tools/verify-explanations.cjs --require-complete` 核對全部題目解析覆蓋、四項理由、來源格式及答案顯示；`node tools/test-explanations-integration.cjs` 檢查非同步載入、作答保密、現有紀錄及失敗提示。

題庫收錄明細以網站「題庫／備份」及 `data/bank.json` 為準；不將可閱讀的申論原卷宣稱為已完成線上申論題庫。

題幹後方固定標示「民國年（西元年）｜原始三等／四等｜移民行政｜原科目｜原題號」，與練習輪次題號分開。閱讀／克漏字題保留原文的共用題幹及作答指示，不以系統自行生成的句子充作歷屆原題。介面參考阿摩的逐題呈現與試題出處標示，原題及判分依據仍為考選部。
